# Input-mode icons

Pixel-art taskbar icons (23×23) for the input daemon's modes, installed to
`overlay/usr/local/share/rg35xxh/icons/inputmode-{desktop,gamepad,bt,wired}[-light].png`
and shown by Waybar's `image#inputmode` module (`rg35xxh-inputmode`).

- `gen_base.py` — the pixel art (one string grid per drawing; gamepad/BT/wired show an RG35XX H: D-pad, coloured X/A/B/Y, dark screen with glare, 3x3 sticks; all widths and heights odd so they centre exactly) and the glass frame (rounded square, 1 px ring, translucent tint).
- `gen_rainbow.py` — dark-taskbar set: external modes (BT, wired) get diagonal rainbow stripes (gradient, saturation 0.65, value 0.58) with a 1 px opaque dark outline (`OUTLINE`) around the drawing where the stripes stop, so the white handheld also stays visible on a light background (External Controller mode picker). The final set is the third variant, written as `grad65-2-<mode>.png`.
- `gen_light.py` — light-taskbar set (`inputmode-<mode>-light.png`): dark drawing, pastel glass, deeper ring; needs the dark PNGs in the same folder for its preview.

- `gen_shake.py` — shake frames (`inputmode-<mode>[-light]-shake<dx>.png`, dx = -2, -1, 1, 2): the drawing shifted sideways inside the glass. the input daemon shows them on the old icon (one damped-spring swing per 60 ms frame, ~0.36 s) before switching to the new one, vibrating in step.
- `gen_battery.py` — taskbar battery icons (`battery[-charging][-low]-<bars>[-light].png`, 20x11): shell always white/ink, 5 bars of 20 %, red bars at 0-20 %, a yellow bolt (1 px clear outline) while charging. Run with the icon folder as the argument. `rg35xxh-battery --animate` steps the charging animation (bars from the current level up to full).

Run in a scratch folder (they write preview PNGs next to themselves): `python3 gen_rainbow.py && python3 gen_light.py && python3 gen_shake.py`. Needs Pillow.
- `gen_app_icons.py <icon folder>` — app drawer icons: `app-theme.png`, `app-external-controller.png` and `app-display.png` (monitor + HDMI cable + RG35XX H, teal glass), `app-ssh.png` (terminal saying SSH + key, green glass), each with a `-light` variant (27x27 art doubled + 1 px margin = exactly 56 px, the drawer's icon size).
- `gen_bt_icons.py <hicolor folder>` — Bluetooth, no frame: the blueman tray states (`blueman-tray` / `-active` with a green dot / `-disabled`, 23 px) and the Bluetooth Manager drawer icon (`blueman`, 56 px), written under blueman's own names into `overlay/usr/local/share/icons/hicolor/` (tray: `22x22/status` + `24x24/status`; drawer: `scalable/status` + `scalable/apps`), the exact folders GTK checks first, so they win over the package's icons.
- `gen_wifi_icons.py <icons folder>` — Wi-Fi / network tray icons for nm-applet under its own names (signal fan with 0-3 lit arcs, no connection, connecting animation, wired), 23 px. Dark set into `hicolor/{22x22,24x24}/apps`, light set into the `Handtop-Light` icon theme (with its `index.theme`), which `rg35xxh-theme light` makes the GTK icon theme. Run with `overlay/usr/local/share/icons`.
- `app-tailscale.png` (no generator): Tailscale's own tray icon, read from `tailscale systray` over D-Bus (StatusNotifierItem IconPixmap, 250 px, connected state: the Tailscale logo) and scaled to 54 px + 1 px margin for the drawer.
- `gen_power_icons.py <icon folder>` — power menu icons (`power-{sleep,reboot,logout,shutdown}[-light|-focus].png`, 24x24 art x3 = 72 px: moon + star, ring with arrowhead, door + arrow, power symbol; blue / amber / grey / red, `-light` darker inks, `-focus` white for the highlighted button in the dark theme) and the taskbar buttons (`panel-apps.png`, 3x3 grid, 16 px white; `panel-power[-light].png`, red power symbol, 24 px). Run with `overlay/usr/local/share/rg35xxh/icons`.
- `gen_logo.py` (run from the repo root) — the Handtop logo (48x48: RG35XX H showing a desktop, keyboard, big pointer, 1 px dark outline) into `media/logo/` (1x, 4x, 8x, SVG, wordmarks for dark / light pages with "Handtop" in a pixel font) and the wallpapers `overlay/usr/local/share/rg35xxh/wallpaper-{dark,light}.png` (640x480, logo 3x + wordmark carved into the wallpaper colour, centred above the taskbar).
