# RG35XX 2024

Evidence for the Handtop profile of this model (phase P1). Nothing here is built or tested yet.

## Sources

- ROCKNIX **20261001** H700 image (the one Handtop builds from, checksum in `build/config.sh`): device trees `sun50i-h700-anbernic-rg35xx-2024.dtb`, `sun50i-h700-anbernic-rg35xx-2024-rev6-panel.dtb` and its panel firmware; summarised in [h700-20261001-facts.json](h700-20261001-facts.json) by `ports/tools/dt-facts.py`.
- ROCKNIX H700 installation guide ([rocknix.org](https://rocknix.org/configure/h700-installation/)).
- ROCKNIX device page ([rocknix.org](https://rocknix.org/devices/anbernic/rg35xx-2024/)) (not read for this page).

## From the device tree

| Item | Value |
|---|---|
| `rg35xx-2024` panel | `anbernic,rg35xx-plus-panel`: 640×480, 70×53 mm |
| `rg35xx-2024-rev6-panel` panel | `anbernic,rg35xx-plus-rev6-panel`: 640×480, 70×53 mm |
| Gamepad | `rocknix-singleadc-joypad`, name "H700 Gamepad", 17 button codes (same set as the RG35XX H) |
| Stick axes | 0 (`amux-count`); inverted: absx, absy |
| Motor | PWM channel 2 |
| Other keys | Key Volume Up, Key Volume Down |
| LEDs | power, status |
| Wi-Fi / Bluetooth | none |
| HDMI | enabled |
| USB | `usb@5100000`, `usb@5101000`, `usb@5101400` (OTG controller only) |
| RTC | allwinner,sun50i-h616-rtc |

## Notes

- **No Wi-Fi or Bluetooth** in the device tree (no `wifi@1`, no Bluetooth node), and no external RTC.
- No sticks.
- Same panels as the RG35XX H / Plus (regular and rev6).
- Stock firmware: not available yet (the "35XX双" image is the original RG35XX, Actions SoC, not H700).

## Not confirmed

- Which ROCKNIX device tree each PE6 level means is inferred (low = the second panel: rev6 / v2) and needs one unit of each panel to confirm.
- Without radios: no Bluetooth controller modes, no Wi-Fi features; desktop works with USB networking only.
- RAM type per batch: not confirmed.
